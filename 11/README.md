# Демонстрация кэширования в FastAPI

Этот сервис демонстрирует использование двух видов кэширования:
1. Локальный LRU кэш с использованием `functools.lru_cache`
2. Распределенный кэш Redis

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск Redis (опционально)

Для полноценной работы с Redis рекомендуется запустить сервер:

```bash
# Через Docker
docker run -d -p 6379:6379 redis:alpine

# Или через системный менеджер пакетов
brew install redis
brew services start redis
```

## Запуск сервиса

```bash
uvicorn main:app --reload
```

Сервис будет доступен по адресу: http://localhost:8000

## Эндпоинты

### 1. Вычисление чисел Фибоначчи с LRU кэшем
```
GET /compute/{n}
```
Демонстрирует использование `@lru_cache` из functools. Первый вызов с каждым значением n будет медленным, последующие - быстрыми.

### 2. Получение данных пользователя с Redis кэшем
```
GET /users/{user_id}
```
Демонстрирует использование Redis для кэширования данных. Первый запрос к пользователю будет медленным, последующие - быстрыми.

### 3. Тяжелые вычисления с Redis кэшем
```
GET /expensive/{n}
```
Демонстрирует кэширование результатов тяжелых вычислений в Redis.

### 4. Очистка всех кэшей
```
POST /cache/clear
```
Очищает все кэши (LRU и Redis).

### 5. Информация о кэшах
```
GET /cache/info
```
Возвращает информацию о состоянии кэшей.

## Как это работает

### LRU кэш (functools.lru_cache)
- Декоратор `@lru_cache` автоматически кэширует результаты функции
- При повторном вызове с теми же аргументами возвращается закэшированный результат
- Автоматически удаляет старые записи при превышении лимита (128 записей)

### Redis кэш
- Хранит данные во внешнем хранилище
- Позволяет разделять кэш между несколькими экземплярами приложения
- Ручное управление: проверка наличия в кэше, сохранение, установка времени жизни
