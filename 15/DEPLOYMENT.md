# FastAPI Application with Redis Caching and Docker Setup

## Что было реализовано:

1. **Добавлено подключение к Redis и кэширование**:
   - Подключение к Redis добавлено в `main.py` с использованием lifespan handler
   - Кэширование реализовано для эндпоинта получения всех товаров (`GET /items/`) в `services.py`
   - Используется Redis для хранения кэша на 5 минут

2. **Создан Dockerfile** для FastAPI сервиса:
   - Используется образ python:3.11-slim
   - Установка всех необходимых зависимостей из requirements.txt
   - Автоматический запуск миграций при старте контейнера
   - Запуск приложения через uvicorn

3. **Создан docker-compose.yml** файл:
   - Сервис PostgreSQL (порт 5432)
   - Сервис Redis (порт 6379)
   - Сервис FastAPI (порт 8000)
   - Настроен healthcheck для всех сервисов
   - Использованы именованные volumes для персистентности данных

4. **Добавлены миграции с помощью Alembic**:
   - Инициализирован Alembic
   - Создана начальная миграция с таблицами items, orders и order_items
   - Настроен env.py для работы с асинхронными моделями

5. **Обновлен requirements.txt**:
   - Добавлены все необходимые зависимости
   - Включены fastapi, uvicorn, sqlalchemy, asyncpg, pydantic, alembic, redis, async-lru

## Как запустить приложение:

1. Убедитесь, что Docker и docker-compose установлены
2. Перейдите в директорию проекта
3. Запустите все сервисы:
   ```
   docker-compose up -d
   ```

4. Приложение будет доступно по адресу: http://localhost:8000

5. Документация API: http://localhost:8000/docs

## Эндпоинты для тестирования кэширования:

- `GET /items/` - получение всех товаров (результаты кэшируются в Redis)
- `POST /items/` - создание нового товара (инвалидирует кэш)
- `PUT /items/{item_id}` - обновление товара (инвалидирует кэш)
- `DELETE /items/{item_id}` - удаление товара (инвалидирует кэш)
- `GET /redis-health` - проверка состояния подключения к Redis

## Миграции:

При запуске контейнера автоматически выполняются все миграции:
```
alembic upgrade head
```

Для создания новых миграций вручную:
```
alembic revision --autogenerate -m "Migration description"
```

## Переменные окружения:

- DATABASE_URL - строка подключения к PostgreSQL
- REDIS_URL - строка подключения к Redis

В docker-compose.yml уже настроены правильные значения этих переменных.
